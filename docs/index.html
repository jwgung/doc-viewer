Download

The app is not code-signed yet, so your system may warn you the first time. Here is how to open it.

Windows 10 / 11

Installer (recommended) or MSI package.

Setup (.exe) .msi

If SmartScreen appears: More info → Run anyway. On older Windows 10 without WebView2, the installer downloads it once.

macOS

One file for Apple silicon and Intel Macs.

Disk image (.dmg)

Not notarized yet: right-click the app → Open, or allow it in System Settings → Privacy & Security.

Linux

Ubuntu 22.04 or newer and similar distributions.

.deb AppImage

For the AppImage, make it executable (chmod +x) and run it.

FAQ

Are my documents uploaded anywhere?

No. Doc Viewer has no server. Files are read from your disk and rendered inside the app.

Can I edit documents?

No — it is a viewer, focused on opening documents quickly and accurately.

Why does a document look slightly different from Office or Hangul?

Rendering is done by open-source engines, and fonts embedded in documents are not used yet (system fonts are used instead). Please open an issue with a sample file.

Is there a mobile version?

An Android version is in the works.
