어떤 문서든, 가벼운 뷰어 하나로.

PDF·한글(HWP/HWPX)·Word·Excel·PowerPoint를 Windows·macOS·Linux에서 인터넷 없이 엽니다. 계정도, 오피스 설치도, 업로드도 필요 없습니다.

무료 · 최신 버전 · GitHub에서 소스 보기

보는 데만 집중했습니다

모든 문서를 앱 안에서 그립니다. 문서는 컴퓨터 밖으로 나가지 않습니다.

📄

여러 형식을 앱 하나로

PDF, 한글, DOC/DOCX, XLS/XLSX/CSV, PPT/PPTX, 마크다운, 텍스트 등. 확장자가 틀려도 내용으로 알아봅니다.

🪟

화면 나누기

탭이나 파일을 가장자리로 끌어 놓으면 최대 4칸으로 나뉩니다. 경계선을 끌어 크기를 바꿉니다.

🗂️

폴더 탐색기 + 탭

폴더를 열고 여러 문서를 탭으로 띄웁니다. 사이드바에서 이름 바꾸기·휴지통·위치 열기도 됩니다.

🔁

보던 그대로 다시

탭·보던 쪽·확대·나눈 화면이 다음에도 그대로. Ctrl+Shift+T로 닫은 탭도 되살립니다.

🎬

슬라이드 속 동영상

PPTX에 들어 있는 동영상·소리를 슬라이드 위에서 바로 재생합니다.

🔒

안심

서버도, 계정도, 사용 기록 수집도 없습니다. 인터넷이 없어도 됩니다.

이렇게 씁니다

탭이나 파일을 가장자리로 끌어 놓으면 화면이 나뉩니다.

내려받기

아직 코드 서명이 없어 처음 열 때 경고가 뜰 수 있습니다. 여는 방법을 함께 적어 두었습니다.

Windows 10 / 11

설치 프로그램(추천) 또는 MSI 패키지.

설치 프로그램 (.exe) .msi

SmartScreen이 뜨면 추가 정보 → 실행. WebView2가 없는 구형 Windows 10은 설치할 때 한 번 내려받습니다.

macOS

Apple 실리콘·Intel Mac 공용 파일 하나.

디스크 이미지 (.dmg)

아직 공증 전이라 앱을 우클릭 → 열기, 또는 시스템 설정 → 개인정보 보호 및 보안에서 허용합니다.

Linux

Ubuntu 22.04 이상 등.

.deb AppImage

AppImage는 실행 권한을 주고(chmod +x) 실행합니다.

자주 묻는 질문

문서가 어딘가로 올라가나요?

아니요. 서버가 없습니다. 내 디스크의 파일을 읽어 앱 안에서 그립니다.

편집도 되나요?

아니요. 빠르고 정확하게 여는 데 집중한 뷰어입니다.

오피스·한글에서 보던 것과 조금 달라요.

오픈소스 엔진으로 그리고, 문서에 들어 있는 글꼴은 아직 쓰지 않고 시스템 글꼴로 보여 줍니다. 예시 파일과 함께 이슈를 남겨 주시면 큰 도움이 됩니다.

모바일 판도 있나요?

Android 판을 준비하고 있습니다.
